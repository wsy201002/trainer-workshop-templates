### 模块一：TNA 基础认知 / TNA Fundamentals (30分钟)

#### 1.1 什么是培训需求分析 / What is TNA

- **定义**：识别"当前能力"与"目标能力"之间差距，并确定培训是否能解决该差距的系统化过程
- **核心公式**：培训需求 = 目标绩效 - 当前绩效（当差距可通过学习缩小）
- **不是所有问题都需要培训**：流程缺陷、设备问题、激励不足 ≠ 培训需求

#### 1.2 TNA 的三个层次 / Three Levels of TNA

| 层次 / Level | 分析对象 / Focus | 关键问题 / Key Question | 典型方法 / Method |
|-------------|-----------------|----------------------|------------------|
| 组织分析 / Organizational | 公司战略、业务目标 | "公司需要什么能力？" | 战略解码、管理层访谈、审核发现 |
| 任务分析 / Task | 岗位职责、SOP、技能矩阵 | "岗位需要什么技能？" | 岗位观察、SOP分析、专家访谈 |
| 人员分析 / Individual | 具体员工的能力现状 | "这个人缺什么？" | 技能测评、绩效数据、考核结果 |

#### 1.3 TNA 在培训流程中的位置 / TNA in Training Process

```
组织/业务变化 ──→ TNA 需求分析 ──→ 培训计划 ──→ 培训实施 ──→ 考核认证 ──→ 效果评估
   ↑                                                                              │
   └──────────────────────── 反馈循环 / Feedback Loop ───────────────────────────┘
```

对应 RACI 矩阵模块二 (2.1-2.6)：

| 场景 / Scenario | 触发条件 / Trigger | RACI责任人 / Owner |

| 新员工入职 | HR招聘计划确认 | TC(R) / HR(A) |
| 在岗技能差距 | 技能矩阵/绩效数据异常 | TC(R) / HR(A) |
| 转岗/调岗 | 岗位变动确认 | TC(R) / HR(A) |

| 5M1E问题 | 质量/安全/工艺异常 | TC(R) / HR(A) |
| 客户审核/验厂 | 审核发现不符合项 | TM(R) / HR(A) |

### 模块二：数据收集方法 / Data Collection Methods (30分钟)

#### 2.1 五种核心收集方法

| 方法 / Method | 适用场景 / When to Use | 优点 / Pros | 缺点 / Cons | 实操要点 / Tips |
|--------------|----------------------|------------|------------|----------------|
| 问卷调查 / Survey | 大批量、标准化信息收集 | 覆盖面广、成本低 | 回收率不可控、主观偏差 | 问题控制在15题以内，包含开放式问题 |
| 访谈 / Interview | 深入了解、敏感话题 | 信息深入、可追问 | 耗时、受访谈者技巧影响 | 提前准备访谈提纲，每次1-2人，30-45分钟 |
| 现场观察 / Observation | 实操技能评估、行为分析 | 客观真实 | 影响正常生产、样本量小 | 用检查表(Checklist)记录，避免主观判断 |
| 绩效数据分析 / Performance Data | 量化差距、趋势判断 | 客观、可比 | 数据质量依赖系统 | 对比目标值、历史数据、同行基准 |
| 专家/管理层输入 / Expert Input | 战略层面、未来需求 | 前瞻性、全局观 | 可能脱离一线实际 | 用结构化提问，避免泛泛而谈 |

#### 2.2 数据收集矩阵 / Data Collection Matrix

| 数据类型 / Data Type | 来源 / Source | 收集频率 / Frequency | 收集人 / Collector | 工具 / Tool |
|---------------------|--------------|---------------------|-------------------|------------|
| 技能矩阵数据 | 技能看板/系统 | 每月更新 | 培训师(TR) + TC | 技能矩阵表 |
| 质量缺陷数据 | 质量部报表 | 每周 | TC | QC报表 |
| 审核发现 | 客户审核/内审报告 | 按审核 | TM + HR | 审核报告 |
| 新员工清单 | HR入职计划 | 按需 | HR | 招聘计划表 |
| 岗位变动 | HR调动通知 | 按需 | HR | 调动记录 |
| 员工反馈 | 问卷/座谈会 | 每季度 | TC | 问卷模板 |

### 模块三：TNA 报告结构 / TNA Report Structure (30分钟)

#### 3.1 标准TNA报告模板

一份完整的 TNA 报告应包含以下 7 个部分：

**第1部分：背景与目的 / Background & Purpose**
- 触发事件（什么引起了这次TNA？）
- 分析范围（涉及哪些岗位/人员/技能？）
- 业务影响（不培训会有什么后果？）

**第2部分：分析方法 / Methodology**
- 使用了哪些数据收集方法
- 样本量与覆盖范围
- 数据来源与时间窗口

**第3部分：现状分析 / Current State Analysis**
- 当前能力水平（数据+事实）
- 目标要求（标准/SOP/客户要求）
- 差距量化（多少人/什么技能/差多少）

**第4部分：差距分类与优先级 / Gap Classification & Priority**
- 按紧急程度：紧急(立即)/重要(本月)/常规(季度)
- 按影响范围：全员/特定岗位/特定班次
- 按风险等级：审核风险/质量风险/安全风险

**第5部分：培训方案建议 / Training Recommendations**
- 培训内容建议（按差距列出）
- 培训方式建议（理论/OJT/外部培训）
- 资源需求（培训师/教材/时间/预算）

**第6部分：行动计划 / Action Plan**
- 培训项目清单
- 时间表
- 责任人
- 验收标准

**第7部分：附录 / Appendices**
- 原始数据
- 问卷/访谈提纲
- 参考文件

### 模块四：TNA 报告编写实操 / TNA Report Writing Practice (45分钟)

#### 4.1 实操案例：VT审核触发TNA

**背景**：VT审核发现以下不符合项：
1. 3名操作员无有效上岗资格证
2. 培训记录不完整，缺少实操考核记录
3. 技能矩阵未更新超过2个月

**练习要求**：每组完成一份TNA报告（第3-6部分）

#### 4.2 分步指导

**Step 1：差距量化（15分钟）**
- 列出每个不符合项对应的能力差距
- 量化：涉及多少人、哪些岗位、缺失什么

| 不符合项 | 涉及岗位 | 人数 | 差距描述 | 风险等级 |
|---------|---------|------|---------|---------|
| 无上岗证 | 注塑操作工 | 3 | 未通过理论+实操考核 | 高(审核) |
| 记录缺失 | 全体培训师 | 5 | 未按流程记录培训过程 | 中(流程) |
| 矩阵未更新 | 所有岗位 | 45 | 技能数据滞后2个月 | 中(管理) |

**Step 2：制定培训方案（15分钟）**

| 培训项目 | 培训内容 | 培训对象 | 培训方式 | 培训师 | 预计时长 | 验收方式 |
|---------|---------|---------|---------|-------|---------|---------|
| 上岗资格补考 | 理论+实操 | 3名无证员工 | 理论课+OJT | TR | 2天 | 考核合格 |
| 培训记录规范 | 记录流程与要求 | 5名培训师 | 集中培训 | TC | 2小时 | 模拟填写 |
| 技能矩阵更新 | 全员技能评估 | 45人 | 培训师逐个评估 | TR | 1周 | 矩阵100%更新 |

**Step 3：行动计划（15分钟）**

| 任务 | 负责人 | 协助人 | 开始日期 | 完成日期 | 验收标准 |
|-----|-------|-------|---------|---------|---------|
| 安排3人补考 | TC | TR | D+1 | D+5 | 100%通过考核 |
| 培训记录培训 | TC | TM | D+2 | D+3 | 5人全部完成 |
| 技能矩阵更新 | TR | TC | D+1 | D+7 | 矩阵100%更新 |
| TNA报告提交 | TC | TM | D+1 | D+3 | 报告完整准确 |

#### 4.3 小组汇报与评审（每组5分钟）

- 各组展示TNA报告
- 交叉评审：其他组提出改进建议
- 讲师点评：对照标准模板评分

### 模块五：常见错误与注意事项 / Common Pitfalls (15分钟)

#### 5.1 TNA 报告的常见错误

| 错误 / Pitfall | 表现 / Symptom | 正确做法 / Fix |
|---------------|---------------|---------------|
| 把"问题"当"需求" | "员工态度差，需要培训" | 先分析是否真的是培训能解决的问题 |
| 数据不充分 | "我觉得员工需要培训" | 用数据说话：绩效数据、技能矩阵、审核发现 |
| 范围过大 | 一次分析所有岗位所有技能 | 聚焦：一次TNA解决一个/一类问题 |
| 缺少优先级 | 列出20个需求但不排序 | 用紧急-重要矩阵排序，聚焦Top 5 |
| 方案不具体 | "加强培训" | 明确：培训内容、对象、方式、时间、验收标准 |
| 忽略非培训因素 | 所有问题都用培训解决 | 区分：培训解决 vs 管理解决 vs 系统解决 |

#### 5.2 TNA 质量检查清单 / Quality Checklist

编写完 TNA 报告后，逐项检查：

- [ ] 触发事件是否明确？（为什么做这次TNA）
- [ ] 数据来源是否可信？（是否有数据支撑）
- [ ] 差距是否量化？（多少人/什么技能/差多少）
- [ ] 优先级是否清晰？（紧急程度和影响范围）
- [ ] 培训方案是否具体？（内容/对象/方式/时间/验收）
- [ ] 责任人是否明确？（RACI对应）
- [ ] 时间表是否合理？（考虑生产安排）
- [ ] 验收标准是否可测量？（不是"提高"而是"达到X%"）
