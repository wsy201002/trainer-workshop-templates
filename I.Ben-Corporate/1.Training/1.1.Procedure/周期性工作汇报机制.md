## 二、月报 (Monthly Report)

**发送人：** 培训主管 (TS) → 审核：培训经理 (TM)
**接收人：** 4位项目经理 (PM) + 制造总监 (MD)
**抄送：** HR培训专员 (Iman)
**发送时间：** 次月第3个工作日 17:00
**形式：** PPT (10-12页) 或 PDF

### 月报内容结构

#### 第1页：Executive Summary (管理层摘要)
- 本月核心KPI仪表盘 (红/黄/绿)
- 重大成就/里程碑
- 关键风险与升级事项
- 需要管理层决策的事项 (不超过3项)

#### 第2页：KPI仪表盘

| KPI | 目标 | 本月实际 | 上月实际 | 趋势 | 状态 |
|-----|------|----------|----------|------|------|
| 培训完成率 | ≥95% | | | ↑/↓/→ | 🟢/🟡/🔴 |
| 新员工上岗周期 | ≤14天 | | | | |
| 新员工首次考核通过率 | ≥85% | | | | |
| 技能矩阵覆盖率 (L2+) | ≥70% | | | | |
| 关键工序持证率 | 100% | | | | |
| 培训记录完整率 | 100% | | | | |
| 培训出勤率 | ≥90% | | | | |
| 审核不符合项整改率 | 100% | | | | |

#### 第3页：各项目经理分视图
分别列出 Vestas前道/后道、Nordex前道/后道 的核心数据对比

#### 第4页：新员工培训趋势
- 月度入职人数趋势图
- 新员工上岗周期趋势
- 新员工质量缺陷率 (与培训关联)

#### 第5页：技能矩阵状态
- 各工序持证人数 vs 需求人数
- 单点风险工序清单 (仅1人持证)
- 多能工比例趋势
- 资质到期预警 (30/60/90天)

- 活跃培训师人数与工作量分布

- 培训师能力提升进度
- 培训师流失/新增

#### 第7页：培训记录与合规
- 记录完整性趋势 (签到/实操/照片/系统录入)
- VT审核整改进度
- 内审/外审发现趋势

- 新员工 vs 老员工质量缺陷率对比
- 培训不足导致的返工趋势
- 上岗后30天内操作失误率

#### 第9页：培训预算与资源
- 预算执行率
- 人均培训成本
- 培训占用生产工时

#### 第10页：上月行动项跟踪
| 序号 | 上月行动项 | 负责人 | 计划完成日 | 当前状态 | 备注 |
|------|-----------|--------|-----------|----------|------|
| | | | | 🟢/🟡/🔴 | |

## 三、季报 (Quarterly Report)

**发送人：** 培训经理 (TM)
**接收人：** 制造总监 (MD)
**抄送：** 4位项目经理 (PM)、HR培训专员 (Iman)
**发送时间：** 次季度第1周
**形式：** PPT (15-20页)

### 季报额外内容

1. **季度趋势分析** (vs 上季度、vs 去年同期)
2. **培训ROI分析** (培训投入 vs 质量改善/效率提升)
3. **培训体系成熟度评估** (按CMMI或内部标准)
4. **跨项目对比分析** (Vestas vs Nordex)
5. **行业标杆对比** (如有)
6. **下季度战略计划** (对齐业务目标)
7. **团队能力矩阵更新** (全团队)
8. **培训课程体系评估与更新计划**
9. **年度目标达成进度** (YTD)
10. **重大风险与应对策略**

## 四、专项报告 (Ad-hoc Reports)

### 4.1 审核专项报告
**触发条件：** VT外审/内审前后
**接收人：** 制造总监 + 4位项目经理
**内容：**
- 审核发现清单 (含培训相关项)
- 整改计划与时间表
- 责任人分配
- 预计完成日期
- 需要的资源支持

### 4.2 质量事件培训响应报告
**触发条件：** 重大质量事故/客户投诉
**接收人：** 制造总监 + 相关项目经理
**内容：**
- 事件描述
- 培训相关根因分析
- 立即纠正措施
- 预防性培训安排
- 效果验证计划

### 4.3 新员工批量入职培训报告
**触发条件：** 大批量新员工入职 (≥10人)
**接收人：** 相关项目经理
**内容：**
- 入职批次与人数
- 培训计划排期
- 培训资源需求
- 预计独立上岗时间

## 五、日常沟通机制

| 频率 | 形式 | 参与者 | 内容 |
|------|------|--------|------|
| 每日 | 班前会5分钟 | 班组长+培训师 | 当日培训安排 |
| 每周 | 周例会30分钟 | TS+TR+TC | 周度培训复盘与下周计划 |
| 每月 | 月度复盘会1小时 | TM+TS+TR | 月度数据复盘+能力提升 |
| 每月 | 与项目经理对齐会30分钟 | TS+PM | 培训与生产计划对齐 |
| 每季度 | 季度评审会2小时 | TM+TS+PM+MD | 季度报告+战略对齐 |
